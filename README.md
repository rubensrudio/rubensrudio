## 🚀 Featured projects

### 🎙️ [Interview Reviewer](https://github.com/rubensrudio/interview-reviewer) — *AI interview platform*
End-to-end platform that analyzes resumes, runs technical interviews, evaluates answers, and generates source-backed assessment reports using local LLMs.
`Python · FastAPI · Angular · Local LLMs`

### 📚 [AI Research Assistant](https://github.com/rubensrudio/AI-Research-Assistant) — *local-first RAG for documents*
Document research platform with JWT auth, vector search over Nomic embeddings, and a local Llama 3.1 8B served by LM Studio.
`FastAPI · SQLAlchemy · Qdrant · Llama 3.1 · Docker Compose`

### 🛢️ [OilOps PredictiveCore](https://github.com/rubensrudio/OilOps-PredictiveCore) — *predictive maintenance for energy*
Explainable anomaly detection on equipment telemetry, built as vendor-neutral, self-hostable microservices.
`FastAPI · ONNX Runtime · Angular`

### 🌋 [AI Compress Seismic](https://github.com/rubensrudio/AI-Compress-Seismic-v1) — *AI-assisted SEG-Y compressor*
Java codec pipeline combined with a TensorFlow autoencoder, exposed through a REST API, a CLI, and an Angular UI.
`Java · TensorFlow · REST · Angular`

### 🔐 [SecureMicro Energy Templates](https://github.com/rubensrudio/SecureMicro-Energy-Templates) — *secure-by-default Spring Boot*
Production-grade microservice templates aligned to NIST SP 800-53 and CISA Secure by Design: OIDC, secrets management, SBOM, threat models, and CVE-gated CI.
`Java · Spring Boot · Keycloak · Vault · OpenTelemetry`

### 🎫 [Support Ticket AI](https://github.com/rubensrudio/support-ticket-ai) — *deep learning ticket triage*
Classifies support tickets, predicts priority, and returns confidence scores, with a focus on evaluation and reproducibility.
`PyTorch · Hugging Face · FastAPI · MLflow · Docker`
